# frontend-lab

Experimentos pequenos e verificáveis de HTML, CSS e JavaScript aplicados a interface.

O objetivo não é acumular tutoriais. Cada exemplo documenta uma decisão concreta de layout ou interação.

## Exemplos

### responsive-grid
Grid de cards que muda por espaço disponível, sem depender de nomes de dispositivos.

### accessible-tabs
Tabs progressivas com teclado e atributos ARIA.

### filterable-list
Filtro simples de conteúdo com JavaScript, mantendo o conteúdo disponível no HTML.

## Princípios

- HTML semântico primeiro;
- CSS responsivo orientado pelo conteúdo;
- JavaScript apenas quando acrescenta comportamento;
- foco visível;
- redução de movimento;
- nenhuma biblioteca obrigatória.
